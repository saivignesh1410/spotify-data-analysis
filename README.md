# Spotify Data Analysis Dashboard

## Project Overview
This project analyzes Spotify data to uncover insights about song popularity, artist trends, and audio features.

## Tools Used
- Python (Pandas, Matplotlib)
- Power BI

## Key Insights
- Most songs fall in medium popularity range (40–60)
- Pop and EDM dominate the dataset
- Moderate energy songs perform better

## Files
- spotify_analysis.py → Python analysis
- clean_spotify.csv → Processed dataset
- spotify_dashboard.pbix → Power BI dashboard
